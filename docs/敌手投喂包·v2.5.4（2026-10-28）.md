## 四 · ★★★★ 我打不穿的地方（★ 敌手该从这里下手）

**★ 这一节是本包的重心。** 下面每一条都是**我明知有洞而无从验证**的：

### 4.1 「不联网」是**静态扫 import**，不是**抓包**

**★ 我做的**：扫核心链路的 `import`，断言没有 `requests` / `socket` / `httpx` 等。

**★★ 而它漏掉的**：
- **`socket` 可以不用 import 就拿到** —— ★ 例如 `__import__("socket")`、`importlib.import_module(...)`、`eval`；
- **★★ 依赖里的传递网络** —— ★ `numpy` / `sklearn` 自己不联网，**而它们的 C 扩展可能有遥测**（★ 我没查）；
- **★★★ `jieba` 首次运行会写缓存** —— ★ 那**不是网络**，但**它也是"往外写东西"**；
- **④ 子进程** —— ★ `subprocess` 可以跑一个 `curl`，而**扫 import 完全看不见**。

**⇒ 敌手该问**：**"核心链路不联网"的可核形态，是不是该是"跑一遍抓包"？**
★ 而**那要一个真的抓包器** —— ★ 故我判这条**现在只验了一半**。

### 4.2 「只显形不修正」只验了**两处**

**★ 我找到的**：`test_failure_only_surfaces_never_corrects` · `test_no_machinery_is_surfaced_not_silently_passed`。

**★★ 而它漏掉的**：
- **有没有别的路径在"自动修"** —— ★ 我只看了这两个名字，**没有全仓扫"写回"动作**；
- **★★ `ReturnProtocol` 的 `resume()` 会 `cone.unfreeze()`** —— ★ **那是"修"还是"返回"？** 界限在哪；
- **★★★ CLI 的 `de` 命令会不会替人改卡** —— ★ 我没试。

**⇒ 敌手该问**：**"不修正"的判据是"没有写回调用"，还是"没有人被改"？**

### 4.3 性质⑤那个实现，**没有调用点**

**★ 我做的**：`check_prompt_version(record, current)` —— 一个纯函数。

**★★ 而它现在的问题**：**没有任何地方调它**。故：
- ★ `de calibrate` 跑完**不会提醒**；
- ★★ `de verify` 也**不会提醒**；
- ★★★ **故 README 那句「引擎主动提醒复检」—— 现在仍然只实现了一半**（"能判"做到了，"主动提醒"没做）。

**⇒ 敌手该攻**：**这一条我该判它"已实现"还是"仍未实现"？**
★ 我自己判**"实现了一半"** —— 而**那个"一半"是我自己划的线**（★ 故它是本包最该被质疑的一条）。

### 4.4 「场景卡是数据」的验证用了一张**我自己写的卡**

**★ 我做的**：`test_property_card_as_data.py` 里现写一张 24 条 core + 12 条 negative 的卡。

**★★ 而它漏掉的**：
- **那不是"用户会写的卡"** —— ★ 那 24 条**是我按"能过锥的约束"编的**；
- **★★ 真实用户的卡可能过不了 `min_length=20`** —— ★ 故"接新场景 = 写一张 JSON 卡"**对不懂约束的人不成立**；
- **★★★ 而 `ValueError: 核心样本不足：需要至少 20 个` 那句只说数字，不说"怎么写才够"**。

**⇒ 敌手该问**：**"写一张 JSON 卡"这句，对**没读过源码的人**成立吗？**

### 4.5 「可返回」我只验了 API 与 input_guards

**★ 我做的**：`test_resume_is_reachable` · `test_return_protocol_does_not_act_on_insufficient_input`。

**★★ 而它漏掉的**：
- **导出的 JSONL/HTML 真的能被别人读回来吗** —— ★ 我没做"导 → 导回"的往返测；
- **★★ "随时离开"** —— ★ 有没有任何状态锁在引擎里？

### 4.6 那个 BOM 守卫是**新的**，而它只查**文件头三字节**

**★ 我做的**：`read(3) == b"\xef\xbb\xbf"`。

**★★ 而它漏掉的**：
- **BOM 可以在文件中间**（★ 例如拼接产生）—— ★ 而标准的"文件头 BOM"只该在最前；
- **★★ 而 `test_no_control_characters_in_any_text_file` 仍然不查 `U+FEFF`** —— ★ 故**中间的 BOM 现在两个守卫都抓不到**。
